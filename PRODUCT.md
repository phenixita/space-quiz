# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static, single-file `index.html`; no server or dependencies.

## Users

Kids and families exploring space together.

## Product Purpose

A 10-question quiz about historic crewed space missions that lets users test what they know, learn from immediate answer feedback, and see a final score.

## Positioning

No distinctive positioning beyond a self-contained, immediately playable quiz was provided.

## Operating Context

Users open the quiz in a browser and complete one short run from start to results.

## Capabilities and Constraints

Show 10 questions about historic crewed space missions, a progress bar, a score counter, green correct-answer feedback, a red shake for incorrect answers, and a results screen with an emoji reaction. Center the content in a narrow column. Use 14–16px sans-serif body text, support `prefers-color-scheme`, and run from one `index.html` without a server or dependencies.

## Evidence on Hand

The project starts empty and has no supplied quiz content, brand assets, or external evidence.

## Product Principles

- Keep the quiz self-contained and immediately usable.
- Make progress and score easy to understand throughout a run.
- Use clear, encouraging feedback after every answer.
